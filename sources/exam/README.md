# 国内学段／考试词形来源

分级不是 CEFR 改名。只提取英文词形和学习阶段，不分发来源书库的释义、例句、图片和音频。

- 小学基础：《义务教育英语课程标准（2022年版）》附录3二级词表，教育部制定，出版社公开PDF：https://www.esph.com.cn/docs/2025-10/705da262a6e74b088ac658bfe2d757ba.pdf 。PDF第95–104页（印刷页88–97）全部渲染并目视核对；505条中504条为单个词头，另有多词项ice cream，不进入单词索引。括号中的明确词形、异体拼写另存 aliases，不从OCR猜修正。
- 小学教材补充：人教版三年级上册至六年级下册8部词表。
- 初中／高中／四级／六级／专八：ChuZhong_2、GaoZhong_2、CET4_2、CET6_2、Level8_2。
- 以上教材及考试词表目录维护者：https://github.com/kajweb/dict ，固定提交及每个原始ZIP摘要见sources.json；这些是教材／备考词表，不冒充全国所有版本课程与官方考试大纲的唯一权威词汇表。

0.4.2新增additional-evidence.json：教育部高中课标2017/2020电子PDF（PDF129–184页）、教育考试院四六级官方大纲2016电子PDF（PDF21–149页）和ECDICT考试标签。记录URL、原文件SHA256、词形、星号对应阶段及页码。高中课标无星为义务教育已学词，*/**为高中新增；CET无星为四级、★为六级。同一行的明确词族与完整变体均保留；缩略拼写、未支持记号行不猜修正，单独列出。原始PDF不纳入仓库，tools/compare_official_levels.py可复现提取。

规则更正：同词与ECDICT明确屈折关系均取最早来源阶段，不再由本词较高等级覆盖原型。hurried→hurry为小学，不能因专八词书单列hurried就忽略基础过去式。同一个拼写仍只存一级。语法缩写按明确展开式计算，不猜副词派生。未覆盖进入专八显示档，不冒充官方认定。

构建时生成data/level-audit.json：逐词记录最终阶段、词频排名以及本词／原型／语法／扩展策略来源。
