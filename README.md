# WordWise 0.4.2 生词提示 · Kindle Scribe 预览版

为 KOReader 2026.07.1 提供当前页英文生词的中文短释义。文字版优先读取原文；没有文字层的扫描页用离线 OCR。全部离线查 StarDict，不联网、不调用 AI。

## 安装

到 [Releases](https://github.com/lujun723-win/wordwise/releases) 下载 `WordWise-Kindle-Scribe-v0.4.2-preview.zip` 完整安装包。当前为预览版，Kindle Scribe 仍待实机验收。

1. Kindle Scribe 已能正常运行 KOReader 2026.07.1。
2. 将安装包内 `koreader/plugins/wordwise.koplugin` 整个目录复制到 Kindle **现有的** `koreader/plugins/` 下，不要多套一层同名目录。
3. 重新启动 KOReader，打开英文书籍。
4. 在顶部菜单的**工具一级列表**找到 **生词提示 · WordWise**，无需进入“更多工具”。如果插件未启用，到插件管理中启用它后重启。

插件自带英文识别模型、离线专名词性模型、三万常用词分级索引和约 36.56 万条 ECDICT 中文短释义 StarDict，不需要另行下载。词典在插件私有目录，原有查词设置不受影响。无需替换 KOReader 核心文件。

## 使用

阅读页右下角显示 **生词提示** 透明文字按钮，无边框、无背景填充，位置在状态栏上方，点击范围保持原来的大小。点击打开快捷弹窗：

- 勾选 **开启提示，翻页自动更新**，用圆钮刻度滑块选择 **小学／初中／高中／四级／六级／专八**；可点刻度或拖动圆钮。点击 **应用**，当前页随即识别，以后翻页自动更新。
- 关闭开关并应用，立即清除当前提示、取消待执行识别，后续翻页不再识别。
- 滑块选择所选等级及以上；越向右，提示范围越少。每页上限仍为 30，不因自动模式改变。
- 点取消或弹窗外部不改设置。系统菜单的 **显示右下角“生词提示”按钮** 可隐藏／恢复按钮，与自动提示总开关独立。

新安装默认关闭自动识别；升级保留已保存的开关。自动处理在页面停止变化0.5秒后开始，快速翻页只处理最后稳定的一页。翻页／关闭／休眠后，旧结果不会重新显示；识别失败明确报告，不静默换算法。

**0.4.1：EPUB单页模式预处理当前页、下一页和上一页。** 缓存就绪后，翻页绘制正文时同时画出译文，避免正文先显示、译文随后补画。后台子进程持有独立阅读位置，不偷偷翻动正在看的页面，也不弹出识别框或拦截翻页。只在内存保留相邻三页的词与坐标，不保存阅读截图。更改布局、字号、难度或关闭提示会作废缓存。

首次开启、跳到未预处理的页面或连续快速翻页时，译文仍需等待后台完成；扫描PDF、连续滚动和双页模式沿用原取词流程，不宣称它们已经支持预载。阅读器定期清残影的全刷与图片页刷新仍由KOReader控制，不会关闭墨水屏本身所需的全刷。

工具菜单仍保留：

- **扫描当前页**：识别屏幕当前显示的英文，按所选级别筛选，最多提示 30 个不同的词。
- **隐藏提示／显示提示**：切换当前页提示可见性，不重复 OCR。
- **清除本页提示**：移除当前结果。
- **生词起点**：六档国内学习阶段，显示所选及以上，默认高中。旧 CEFR 设置升级后重置为高中，需要重新选择；这是重新分级，不是把 CEFR 改名。
- **每页上限**：5／10／15／20／30，默认 30。升级时原来的 20 自动改为 30；较低设置保留。升级后手动选择 20 仍会正常保存，不会每次重启都强制改回 30。
- **统一提示字号**：8／9／10／12／14／16／18，默认 8，保留已有选择。6寸设备可选择18；更大的提示需要更宽行距，放不下仍会略过，不覆盖正文。

插件菜单内的 **触发手势** 直接打开 KOReader 原生手势动作编辑。推荐双指轻点右下角→“生词提示：打开快捷设置”，双指轻点左下角→“生词提示：扫描当前页”。只提供配置入口，不覆盖已有绑定；不支持多点触摸时提供单指下滑再上滑，需开启 KOReader 连续手势。也可在原生动作中选择“开关自动提示”“隐藏／显示”“清除当前页”。不另建识别手势算法，页内按钮只接管自身区域内的单击。

文字版直接取词；扫描页 OCR 时显示进度提示，点击屏幕可取消。翻页、滚动、缩放、旋转或重新排版后清除旧提示，自动开关开启时更新当前页；关闭时仍可通过菜单明确执行单次扫描。

## 原文优先

- EPUB 等文字版通过 CREngine 原始词边界、文字和屏幕坐标取词，不运行 OCR；保留原文撇号和连字符，不会把 `it was` 识别成地名。
- 文字 PDF 通过 MuPDF 原始文字层取词，使用阅读器现有坐标转换；仅有一行文字也直接读取。没有文字层的可见页才选择截图 OCR。
- 原文接口出错会明确报错，不静默换成 OCR。原文在可见范围外也不会伪装成扫描页。
- 原生文字选区包含行距，插件只在原文框内度量截图实际字迹，决定正文占用范围；不从像素猜拼写。非白背景保守视作占用，可能减少提示，但不会为放下释义而覆盖背景内容。
- 菜单扫描结果会注明“原文”或“截图 OCR”。原文取词解决识别错误，不等于上下文翻译；离线短释义仍可能出现不符合语境的多义词首义。

## 显示规则

按 Kindle 生词提示样式，英文单词上方画覆盖词宽的细横向括号（中间凸起），中文释义放在括号上方居中，不画气泡边框或底色。字号保持统一，使用实际渲染的字迹大小，不把 UI 字体自带的上下空白当作释义高度；不缩小单个单词的字号。

中文与括号整体参与正文、页面边界、其它释义及右下角按钮的碰撞检查；放不下就略过，继续尝试下一候选词，最多显示 30 个。状态分别统计 **行距不足、正文碰撞、释义重叠、页边、按钮、超上限**，不再把所有拒绝原因都叫“空间不足”。只在手动扫描没有任何可放置词时提示原因；自动模式不逐页弹无生词或空间提示。

**开启提示时，EPUB 默认自动调到最大行距 200%。** 通过 KOReader 原生 ReaderFont 接口排版，关闭提示恢复该书原行距；开启期间若手动改过行距，关闭时保留手动值。原行距按书保存，重开后仍能恢复。仅修改难度不会反复重置手动行距。固定排版 PDF 不可用这个接口改变行距，密集页面仍可能没有足够空间。

## 人名等专有名词保护

使用 MIT 许可的离线上下文词性模型，先辨认 NNP／NNPS 专有名词，再做小写归一化、去重、分级和查词。`Harry Potter`、`Hermione Granger` 等会被略过；`The potter made a bowl` 中的普通 `potter` 仍可查词。同页先出现姓名 Potter，也不会占掉后面普通 potter 的名额。

这不是“所有大写词都跳过”的规则，也不是逐词姓名黑名单；句首 `After` 等普通词仍保留。它保护的是人名、地名等专名，并非 PERSON 专用实体模型。全小写姓名、小说新造姓名、OCR 错字及上下文歧义仍可能误判，不承诺百分之百。模型随包，无 Python、Java 或新平台二进制依赖。

## 统一分级规则

- 使用 wordfreq 公开英语词频数据，在有中文释义的标准英文词中圈定三万常用词。词频只决定范围及同级提示顺序，不用于推测考试等级。
- 小学参考《义务教育英语课程标准（2022年版）》附录3二级词表及人教小学教材；初中、高中、四级、六级、专八参考对应教材／备考词表。来源及固定提交见 `data/exam-sources.json`，开发资料见 `sources/exam/README.md`；不是宣称全国教材版本或考试大纲只有这一份词表。
- 0.4.2重新在线比对教育部高中课标（2017年版2020修订）、教育考试院CET大纲（2016修订）及ECDICT考试标注，结合既有小学课标、教材词表。只提取电子PDF明确词形和星号标注，不猜修正缩略拼写；未支持行保留审计。来源与页码见data/additional-sources.json，完整提取依据见sources/exam/additional-evidence.json。
- 同词和明确屈折变形取有来源的最早学习阶段，每词仅一级。修正旧版“本词高等级压过原型低等级”：hurried按hurry的明确过去式关系归入小学，不再误留在专八。两个方向的明确词形关系均读取，不按-ed/-ly等后缀猜词。多义词、累积考试词表不能等同绝对难度；本索引面向阅读中较早可能学过的词。
- 三万词全部复核，5,460词改变等级，10,094词仍未被现有词表覆盖，使用专八显示策略。逐词依据保存在data/level-audit.json，变更清单在data/level-comparison-report.json。不同阶段重复收录不等于来源出错，不用多数投票推等级。
- 没有来源或超出三万常用范围的词按用户要求归入专八显示档；这是展示规则，不宣称它们是官方专八词。该档中来源收录和扩展策略分别审计，不混写为全部有权威等级。
- 常用语法缩写按明确展开式计算阶段，单独审计，不按后缀猜词形。例如完整保留 `what is／what has 的缩写`。
- “选择高中”包括高中、四级、六级、专八，不包括小学和初中。
- 相同拼写每页仅提示第一次出现；先批量精确查词，再按等级优先放置，词典没有释义的 OCR 字符串不会占用显示名额。不会猜测修正拼写或词形。
- 短释义不根据上下文判多义词；没有改用蓝思值冒充单词等级。公开词频数据是约截至 2021 年的语料快照，不是实时词频。

原始数据来源、摘要、过滤审计及许可均随构建保存；源数据中 4 条无效短释义没有猜测修补，审计见 `data/source-audit.json`。

## 兼容与验证状态

- 开发目标：Kindle Scribe，KOReader 2026.07.1。
- 复用当前 KOReader 随包的 `libk2pdfopt`、LuaJIT 和 `sdcv`，不捆绑不匹配的 Kindle ABI 二进制。
- 当前为预览版。电脑测试不能代替 Kindle 实机测试；实际速度、中文显示和页面位置需要设备确认。
- 当前只开发英文页内提示；生词本、背诵及 Move 适配不在本版范围内。
- 扫描页仍可能发生 OCR 合词或误识别，文字版不走这条链路。不屏蔽特定地名掩盖错误，也不宣称 OCR 已完全准确。

## 卸载

退出 KOReader，移走 `plugins/wordwise.koplugin` 目录后重启。用户设置在 KOReader 的 `settings/wordwise.lua`，需要彻底清理时可另行移走该文件。
